## 📖 About This Repository

Welcome! 👋

This repository documents a structured, day-by-day journey of learning **Pandas** — one of the most powerful Python libraries for data analysis, data science, and machine learning workflows.

Instead of dumping finished work all at once, each notebook here is added **as a topic is completed**, so the repository doubles as:

- A personal learning log and progress tracker
- A practical, example-driven reference for Pandas
- A beginner-friendly resource for anyone following a similar AI/ML roadmap

📌 **New notebooks are added as soon as each topic is completed** — so this repo is actively growing.

## 🚀 Getting Started

To run these notebooks on your own machine:

```bash
# 1. Clone the repository
git clone https://github.com/zain1234-coder/Pandas-for-AI-ML.git
cd Pandas-for-AI-ML

# 2. (Optional) Create a virtual environment
python -m venv venv
source venv/bin/activate      # On Windows: venv\Scripts\activate

# 3. Install the required libraries
pip install pandas numpy jupyter

# 4. Launch Jupyter Notebook
jupyter notebook
```

Then open any notebook (e.g., `01_pandas_series.ipynb`) and start exploring.
